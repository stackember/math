## Коротко

$$
|a| = \begin{cases} a, & \text{якщо } a \ge 0 \\ -a, & \text{якщо } a < 0 \end{cases}
$$

**Геометричний зміст:** $|a|$ — відстань від 0 до точки $a$; $|a - b|$ — відстань між точками $a$ і $b$.

## Простими словами

Модуль — це **відстань до нуля** на числовій прямій. Відстань не буває від'ємною, тому модуль «прибирає мінус»: $|-5| = 5$ і $|5| = 5$ — обидва числа на відстані 5 від нуля.

### Властивості

- $|a| \ge 0$ завжди
- $|-a| = |a|$
- $|a \cdot b| = |a| \cdot |b|$, $\left|\frac{a}{b}\right| = \frac{|a|}{|b|}$
- $|a|^2 = a^2$, $\sqrt{a^2} = |a|$

### Як розкрити модуль

Визнач знак виразу під модулем: якщо він $\ge 0$ — знімай модуль без змін, якщо $< 0$ — міняй знак.

- $|\sqrt3 - 2| = 2 - \sqrt3$, бо $\sqrt3 \approx 1{,}73 < 2$
- $|\pi - 3| = \pi - 3$, бо $\pi > 3$

### Рівняння й нерівності

| Вигляд | Розв'язок |
|---|---|
| $\lvert x \rvert = a$, $a > 0$ | $x = a$ або $x = -a$ |
| $\lvert x \rvert = 0$ | $x = 0$ |
| $\lvert x \rvert = a$, $a < 0$ | розв'язків немає |
| $\lvert x \rvert < a$ | $-a < x < a$ |
| $\lvert x \rvert > a$ | $x < -a$ або $x > a$ |

## Приклади

- $|x - 3| = 5$ → $x - 3 = 5$ або $x - 3 = -5$ → **$x = 8$ або $x = -2$**
- $|2x - 1| = -3$ → **розв'язків немає** (модуль не буває від'ємним)
- $|x - 1| \le 2$ → $-2 \le x - 1 \le 2$ → **$-1 \le x \le 3$**
- $|x| > 4$ → **$x < -4$ або $x > 4$**

## Пастки

:::caution[Не плутай]
- ❌ $\sqrt{(-3)^2} = -3$. **Ні**: $\sqrt{a^2} = |a|$, тому $\sqrt{(-3)^2} = |-3| = 3$.
- ❌ $|x| = 5$ → $x = 5$. **Ні**, коренів два: $x = 5$ або $x = -5$.
- ❌ $|x| = -3$ → $x = \pm 3$. **Ні**, модуль не буває від'ємним — розв'язків немає.
:::
