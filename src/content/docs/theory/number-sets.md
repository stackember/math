## Коротко

| Множина | Назва | Що входить | Приклади |
|---|---|---|---|
| $\N$ | Натуральні | числа для лічби | $1, 2, 3, \dots$ (**0 — не натуральне**) |
| $\Z$ | Цілі | натуральні, протилежні до них і 0 | $-3;\ 0;\ 7$ |
| $\Q$ | Раціональні | дроби $\frac{m}{n}$, де $m \in \Z$, $n \in \N$ | $\frac12;\ -0{,}75;\ 0{,}(3);\ 5$ |
| $\I$ | Ірраціональні | нескінченні **неперіодичні** десяткові дроби | $\sqrt2;\ \sqrt5;\ \pi$ |
| $\R$ | Дійсні | $\Q$ та $\I$ разом | усі числа на прямій |

**Вкладеність:** $\N \subset \Z \subset \Q \subset \R$, а також $\I \subset \R$. Множини $\Q$ та $\I$ не перетинаються.
Число належить своїй множині **і всім більшим, що її містять**: 5 — натуральне, отже водночас ціле, раціональне і дійсне.

## Простими словами

**Множина** — це набір чисел, ніби «коробка», куди ми складаємо числа за якимось правилом. Кожна нова множина з'явилася, бо старої **не вистачало**:

1. **$\N$ — натуральні** ($1, 2, 3, \dots$). Ними лічимо предмети.
   ❓ $3 - 5 = ?$ Серед натуральних такої відповіді немає.
2. **$\Z$ — цілі.** Додаємо **0 і від'ємні**: $\dots, -2, -1, 0, 1, 2, \dots$ Тепер $3 - 5 = -2$ ✓
   ❓ $1 : 2 = ?$ Серед цілих такої відповіді немає.
3. **$\Q$ — раціональні.** Додаємо **дроби**: $\frac12;\ -\frac34;\ 0{,}25;\ 0{,}(3)$… Тепер $1 : 2 = \frac12$ ✓
   ❓ Діагональ квадрата зі стороною 1 дорівнює $\sqrt2$, а його **неможливо** записати дробом.
4. **$\I$ — ірраціональні** — числа, які **не записуються дробом**: $\sqrt2$, $\sqrt3$, $\pi$.
   Разом із раціональними вони утворюють **$\R$ — дійсні числа**, тобто всі точки числової прямої.

```text
R — дійсні (усі числа на прямій)
├── Q — раціональні (можна записати дробом)
│   ├── Z — цілі (без дробової частини)
│   │   ├── N — натуральні: 1, 2, 3, …
│   │   └── 0 і від'ємні цілі: 0, −1, −2, …
│   └── нецілі дроби: 1/2, −0,75, 0,(3)
└── I — ірраціональні (дробом не записати): √2, √5, π
```

:::tip[Аналогія]
Як адреса: _Київ ⊂ Україна ⊂ Європа_. Хто живе в Києві, той живе і в Україні, і в Європі.
:::

### Звідки взялися букви

| Буква | Від слова | Переклад | Як запам'ятати |
|---|---|---|---|
| $\N$ | **N**atural | натуральні | N = **Н**атуральні |
| $\Z$ | **Z**ahlen (нім.) | «числа» | Z — «зигзаг» туди-сюди від нуля: і «+», і «−» |
| $\Q$ | **Q**uotient | частка (результат ділення) | дріб = ділення |
| $\I$ | **I**rrational | ірраціональні | I = **І**рраціональні |
| $\R$ | **R**eal | дійсні («реальні») | R = **R**eal, усі числа на прямій |

У книжках часто пишуть з подвійною рискою: $\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}$ — означають те саме. Замість $\I$ інколи пишуть $\R \setminus \Q$ — «дійсні без раціональних».

### Значки

| Значок | Читається | Приклад |
|---|---|---|
| $\in$ | належить | $5 \in \N$: 5 є натуральним |
| $\notin$ | не належить | $-5 \notin \N$: $-5$ не натуральне |
| $\subset$ | є частиною | $\N \subset \Z$: усі натуральні є цілими |
| $\cup$ | об'єднання | $\R = \Q \cup \I$: дійсні — це раціональні разом з ірраціональними |

## Як визначити множину числа

**Крок 0. Спрости число:** добудь корінь, скороти дріб: $\sqrt{16} \to 4$, $\frac{12}{4} \to 3$, $-\sqrt9 \to -3$.

**Крок 1.** Чи можна записати число **дробом** (скінченним або періодичним десятковим)?

- ❌ Ні → **$\I$** (і $\R$). Кінець.
- ✅ Так → **$\Q$** (і $\R$). Переходь до кроку 2.

**Крок 2.** Чи число **ціле** (без дробової частини)?

- ❌ Ні → тільки **$\Q$, $\R$**. Кінець.
- ✅ Так → **$\Z$** (і $\Q$, $\R$). Переходь до кроку 3.

**Крок 3.** Чи число **більше за 0**?

- ✅ Так → **$\N$** (і $\Z$, $\Q$, $\R$).
- ❌ Ні (0 або від'ємне) → тільки **$\Z$, $\Q$, $\R$**.

### Раціональне чи ірраціональне

- Скінченний десятковий дріб → раціональне: $0{,}25 = \frac14$
- Нескінченний **періодичний** дріб → раціональне: $0{,}(3) = \frac13$
- Корінь із числа, що **не є точним квадратом** → ірраціональне: $\sqrt2$, $\sqrt{12}$.
  Точні квадрати, які варто пам'ятати: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144
- Корінь, що добувається націло → раціональне: $\sqrt{16} = 4$ (ще й натуральне)
- $\pi$ і нескінченні дроби **без періоду** ($0{,}1010010001\dots$) → ірраціональні; $3{,}14$ → раціональне

### Періодичний дріб → звичайний

**Чистий період:** у чисельнику період, у знаменнику стільки дев'яток, скільки цифр у періоді: $0{,}(3) = \frac39 = \frac13$, $0{,}(27) = \frac{27}{99} = \frac{3}{11}$.

**Мішаний період:** від усього числа без коми відніми частину до періоду; у знаменнику дев'ятки — за кількістю цифр у періоді, нулі — за кількістю цифр між комою і періодом: $1{,}2(3) = \frac{123 - 12}{90} = \frac{111}{90} = \frac{37}{30}$.

## Приклади

| Число | $\N$ | $\Z$ | $\Q$ | $\I$ | $\R$ |
|---|:-:|:-:|:-:|:-:|:-:|
| $7$ | ✓ | ✓ | ✓ | – | ✓ |
| $0$ | – | ✓ | ✓ | – | ✓ |
| $-4$ | – | ✓ | ✓ | – | ✓ |
| $\frac25$ | – | – | ✓ | – | ✓ |
| $-1{,}5$ | – | – | ✓ | – | ✓ |
| $0{,}(6)$ | – | – | ✓ | – | ✓ |
| $\sqrt9 = 3$ | ✓ | ✓ | ✓ | – | ✓ |
| $\frac{12}{4} = 3$ | ✓ | ✓ | ✓ | – | ✓ |
| $-\sqrt4 = -2$ | – | ✓ | ✓ | – | ✓ |
| $\sqrt5$ | – | – | – | ✓ | ✓ |
| $\pi$ | – | – | – | ✓ | ✓ |

У кожному рядку галочка стоїть **або в $\Q$, або в $\I$**, і ніколи в обох одразу. А $\R$ є завжди.

**Задача:** які з чисел $-5;\ 0;\ \sqrt9;\ \frac23;\ \sqrt7;\ 0{,}1(6)$ є цілими?
**Розв'язок:** спрощуємо $\sqrt9 = 3$. Цілі: $-5;\ 0;\ 3$. А $\frac23$ і $0{,}1(6)$ — раціональні, але не цілі; $\sqrt7$ — ірраціональне.

## Пастки

:::caution[Не плутай]
- ❌ «0 — натуральне». **Ні**, натуральні починаються з 1.
- ❌ «$\frac{12}{4}$ — дріб, отже не ціле». **Спочатку спрости**: $\frac{12}{4} = 3$, а це натуральне.
- ❌ «$0{,}333\dots$ нескінченне, отже ірраціональне». **Ні**, воно періодичне: $0{,}(3) = \frac13$, тобто раціональне.
- ❌ «$3{,}14 = \pi$». **Ні**: $3{,}14$ раціональне, а $\pi$ ірраціональне, і це різні числа.
- ❌ «Корінь завжди ірраціональний». **Ні**: $\sqrt{25} = 5$, $\sqrt{0{,}25} = 0{,}5$.
:::
