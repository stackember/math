## Коротко про головне

- $\N$ — натуральні: $1, 2, 3, \dots$ (**0 не натуральне**). $\Z$ — цілі: додаємо 0 і від’ємні.
- $\Q$ — раціональні: усе, що записується дробом, зокрема скінченні й періодичні дроби: $0{,}25 = \frac14$, $0{,}(3) = \frac13$.
- $\I$ — ірраціональні, дробом не записати: $\sqrt2$, $\sqrt5$, $\pi$, $0{,}1010010001\dots$ — **$\Q$ та $\I$ не перетинаються.**
- $\N \subset \Z \subset \Q \subset \R$, $\I \subset \R$. Число належить своїй множині **і всім більшим**.
- Спочатку спрости: $\sqrt{16} = 4$, $\frac{12}{4} = 3$, $-\sqrt9 = -3$, $\sqrt{0{,}25} = 0{,}5$.
- $\in$ — належить, $\notin$ — не належить, $\subset$ — є частиною, $\cup$ — об’єднання: $\R = \Q \cup \I$.
