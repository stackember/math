**Множина** — це просто набір чисел, ніби «коробка», куди ми складаємо числа за якимось правилом.

## 1. Звідки взялися множини

Кожна нова множина з'явилася, бо старої **не вистачало**:

1. **$\N$ — натуральні** ($1, 2, 3, \dots$). Ними лічимо предмети: 1 яблуко, 2 яблука…
   ❓ Проблема: $3 - 5 = ?$ Серед натуральних такої відповіді немає.

2. **$\Z$ — цілі.** Додаємо **0 і від'ємні**: $\dots, -2, -1, 0, 1, 2, \dots$
   Тепер $3 - 5 = -2$ ✓
   ❓ Проблема: $1 : 2 = ?$ Серед цілих такої відповіді немає.

3. **$\Q$ — раціональні.** Додаємо **дроби**: $\frac12;\ -\frac34;\ 0{,}25;\ 0{,}(3)$…
   Тепер $1 : 2 = \frac12$ ✓
   ❓ Проблема: діагональ квадрата зі стороною 1 дорівнює $\sqrt2$, а його **неможливо** записати дробом.

4. **$\I$ — ірраціональні.** Це числа, які **не записуються дробом**: $\sqrt2$, $\sqrt3$, $\pi$.
   Разом із раціональними вони утворюють **$\R$ — дійсні числа**, тобто всі точки числової прямої.

## 2. Як множини вкладаються одна в одну

```text
R — дійсні (усі числа на прямій)
├── Q — раціональні (можна записати дробом)
│   ├── Z — цілі (без дробової частини)
│   │   ├── N — натуральні: 1, 2, 3, …
│   │   └── 0 і від'ємні цілі: 0, −1, −2, …
│   └── нецілі дроби: 1/2, −0,75, 0,(3)
└── I — ірраціональні (дробом не записати): √2, √5, π
```

**Головне правило:** число належить своїй множині **і всім більшим, що її містять**.
Наприклад, 5 — натуральне, отже воно водночас ціле, раціональне і дійсне.

:::tip[Аналогія]
Як адреса: _Київ ⊂ Україна ⊂ Європа_. Хто живе в Києві, той живе і в Україні, і в Європі.
:::

## 3. Звідки взялися букви

Це загальноприйняті позначення, ними користуються в усьому світі.

| Буква | Від слова | Переклад | Як запам'ятати |
|---|---|---|---|
| $\N$ | **N**atural | натуральні | N = **Н**атуральні |
| $\Z$ | **Z**ahlen (нім.) | «числа» | Z — «зигзаг» туди-сюди від нуля: і «+», і «−» |
| $\Q$ | **Q**uotient | частка (результат ділення) | дріб = ділення |
| $\I$ | **I**rrational | ірраціональні | I = **І**рраціональні |
| $\R$ | **R**eal | дійсні («реальні») | R = **R**eal, усі числа на прямій |

- У книжках часто пишуть з подвійною рискою: $\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}$ — означають те саме.
- Замість $\I$ інколи пишуть $\R \setminus \Q$, тобто «дійсні без раціональних». На НМТ зазвичай використовують $\I$.

## 4. Значки

| Значок | Читається | Приклад |
|---|---|---|
| $\in$ | належить | $5 \in \N$: 5 є натуральним |
| $\notin$ | не належить | $-5 \notin \N$: $-5$ не натуральне |
| $\subset$ | є частиною | $\N \subset \Z$: усі натуральні є цілими |
| $\cup$ | об'єднання | $\R = \Q \cup \I$: дійсні — це раціональні разом з ірраціональними |

## 5. Алгоритм: до якої множини належить число

**Крок 0. Спрости число:** добудь корінь, скороти дріб.
$\sqrt{16} \to 4$, $\frac{12}{4} \to 3$, $-\sqrt9 \to -3$

**Крок 1.** Чи можна записати число **дробом** (скінченним або періодичним десятковим)?

- ❌ Ні → **$\I$** (і $\R$). Кінець.
- ✅ Так → **$\Q$** (і $\R$). Переходь до кроку 2.

**Крок 2.** Чи число **ціле** (без дробової частини)?

- ❌ Ні → тільки **$\Q$, $\R$**. Кінець.
- ✅ Так → **$\Z$** (і $\Q$, $\R$). Переходь до кроку 3.

**Крок 3.** Чи число **більше за 0**?

- ✅ Так → **$\N$** (і $\Z$, $\Q$, $\R$).
- ❌ Ні (0 або від'ємне) → тільки **$\Z$, $\Q$, $\R$**.

### Як розпізнати ірраціональне

- Корінь із числа, яке **не є точним квадратом**: $\sqrt2, \sqrt3, \sqrt5, \sqrt{12}, \dots$
  Точні квадрати, які варто пам'ятати: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144
- $\pi$
- Нескінченний дріб **без періоду**: $0{,}1010010001\dots$

## 6. Таблиця-тренажер

| Число | $\N$ | $\Z$ | $\Q$ | $\I$ | $\R$ |
|---|:-:|:-:|:-:|:-:|:-:|
| $7$ | ✓ | ✓ | ✓ | – | ✓ |
| $0$ | – | ✓ | ✓ | – | ✓ |
| $-4$ | – | ✓ | ✓ | – | ✓ |
| $\frac25$ | – | – | ✓ | – | ✓ |
| $-1{,}5$ | – | – | ✓ | – | ✓ |
| $0{,}(6)$ | – | – | ✓ | – | ✓ |
| $\sqrt9 = 3$ | ✓ | ✓ | ✓ | – | ✓ |
| $\frac{12}{4} = 3$ | ✓ | ✓ | ✓ | – | ✓ |
| $-\sqrt4 = -2$ | – | ✓ | ✓ | – | ✓ |
| $\sqrt5$ | – | – | – | ✓ | ✓ |
| $\pi$ | – | – | – | ✓ | ✓ |

Зверни увагу: у кожному рядку галочка стоїть **або в $\Q$, або в $\I$**, і ніколи в обох одразу. А $\R$ є завжди.

## 7. Типові помилки

:::caution[Не плутай]
- ❌ «0 — натуральне». **Ні**, натуральні починаються з 1.
- ❌ «$\frac{12}{4}$ — дріб, отже не ціле». **Спочатку спрости**: $\frac{12}{4} = 3$, а це натуральне.
- ❌ «$0{,}333\dots$ нескінченне, отже ірраціональне». **Ні**, воно періодичне: $0{,}(3) = \frac13$, тобто раціональне.
- ❌ «$3{,}14 = \pi$». **Ні**: $3{,}14$ раціональне, а $\pi$ ірраціональне, і це різні числа.
- ❌ «Корінь завжди ірраціональний». **Ні**: $\sqrt{25} = 5$, $\sqrt{0{,}25} = 0{,}5$.
:::
