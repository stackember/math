# Математика · НМТ

Особистий сайт для підготовки до НМТ з математики: теорія і практика за темами.

## Запуск

Потрібен Node.js 22.12+ (рекомендовано 24 LTS, див. `.nvmrc`).

```bash
npm install
npm run dev
```

Сайт відкриється на http://localhost:3000. Навігація — меню зліва, пошук — угорі (або `Ctrl K` / `⌘ K`).

## Як влаштовано

| Розділ      | Що там                                            | Де лежить                     |
| ----------- | ------------------------------------------------- | ----------------------------- |
| 📖 Теорія   | тема: коротко, простими словами, приклади, пастки | `content/theory/<тема>.mdx`   |
| 🏋️ Практика | завдання у форматі НМТ з перевіркою й поясненнями | `content/practice/<тема>.mdx` |

Теорію й практику однієї теми пов'язує однакова назва файлу. Порядок тем — у `content/theory/meta.json`.

## Команди

| Команда            | Що робить                                                         |
| ------------------ | ----------------------------------------------------------------- |
| `npm run dev`      | сайт з автооновленням                                             |
| `npm run verify`   | повна перевірка: типи, лінтер, форматування, тести, збирання, e2e |
| `npm run build`    | продакшн-збирання                                                 |
| `npm run start`    | запуск зібраного сайту                                            |
| `npm run test:e2e` | браузерні тести (після `npm run build`)                           |

Перед першим `npm run test:e2e`: `npx playwright install chromium`.

Правила для AI-агента — у [AGENTS.md](AGENTS.md) (`CLAUDE.md` — посилання на нього).
