# Математика · НМТ

Особистий сайт для вивчення математики за посібниками НМТ (алгебра, геометрія): конспекти тем, власні уроки складних місць і тренажери у форматі НМТ.

## Запуск

Потрібен Node.js 22.12+ (рекомендовано 24 LTS, див. `.nvmrc`).

```bash
npm install
npm run dev
```

Сайт відкриється на http://localhost:4321. Навігація — меню зліва, пошук — угорі.

## Як влаштовано

| Розділ меню                | Що там                                  | Де лежить                                                        |
| -------------------------- | --------------------------------------- | ---------------------------------------------------------------- |
| 📘 Конспект за підручником | стисла теорія теми, приклади, міні-тест | `src/content/docs/topics/`                                       |
| 🧠 Мої уроки               | детальні пояснення складних місць       | `src/content/docs/lessons/`                                      |
| 🏋️ Тренажер                | завдання НМТ з перевіркою й поясненнями | `…/lessons/…/<урок>-trainer.mdx`                                 |
| 📎 Матеріали               | підручники, посилання                   | `src/content/docs/materials.mdx`, фото в `src/assets/materials/` |

## Команди

| Команда                     | Що робить                                           |
| --------------------------- | --------------------------------------------------- |
| `npm run dev`               | сайт з автооновленням                               |
| `npm run verify`            | повна перевірка: типи, лінтер, тести, збирання      |
| `npm run build` / `preview` | зібрати статичний сайт у `dist/` / переглянути його |

Правила для AI-агента — у [AGENTS.md](AGENTS.md) (`CLAUDE.md` — посилання на нього).
