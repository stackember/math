# Математика · НМТ

Особистий сайт для підготовки до НМТ з математики. Кожна тема — це **теорія** (стисло, простими словами, з прикладами й пастками) і, де потрібно, **практика**: тренажер із завданнями у форматі НМТ, поясненнями та збереженням результатів.

Сайт не прив'язаний до конкретних підручників: теми додаються й діляться так, як зручно вчитися.

## Швидкий старт

**Потрібно:** Node.js 22.12+ (рекомендовано 24 LTS — див. `.nvmrc`) і npm.

```bash
npm install
npm run dev
```

Сайт відкриється на **http://localhost:3000**. Зміни у файлах підхоплюються одразу, без перезапуску.

Для браузерних тестів (один раз):

```bash
npx playwright install chromium
```

## Як вчитися з сайтом

1. **Обери тему** в меню зліва (розділ програми → тема → «Теорія»). Назва теми розгортає її пункти.
2. **Прочитай теорію:** коротко → простими словами → приклади → пастки.
3. **Натисни «Практика»** під заголовком теми або в меню всередині теми (є, якщо до теми є тренажер).
4. **Пройди тренажер:** після кожної відповіді — пояснення, у кінці — результат за правилами теми.
5. **Повтори помилки**, а потім пройди тест ще раз: найкращий результат зберігається.

## Навігація та інтерфейс

- **Меню зліва:** «Як вчитися», далі розділи програми («Числа», …) з темами в порядку вивчення. Назва теми розгортає її пункти: «Теорія», «Практика» (якщо є тренажер) і підсторінки; тема без практики — одразу посилання на теорію. Розділи згортаються, а саме меню можна сховати кнопкою вгорі.
- **Над заголовком** — шлях: розділ › тема.
- **Кнопки переходу:** на сторінці теорії — «Практика» (якщо до теми є тренажер), на сторінці практики — «← Теорія».
- **«На цій сторінці»** справа — зміст сторінки з підсвіткою поточного розділу. На вужчих екранах він згортається в меню вгорі сторінки.
- **Унизу сторінки** — картки «Назад / Далі» з повними назвами сусідніх сторінок: з теорії — на практику цієї ж теми, далі — на наступну тему.
- **Тема оформлення:** світла, темна або як у системі — перемикач унизу меню чи клавіша `D`.
- **Телефон:** меню відкривається кнопкою у верхньому правому куті, зміст сторінки — випадаюче меню вгорі, таблиці й схеми вміщаються без горизонтальної прокрутки.
- **Неіснуюча адреса** — сторінка «Сторінку не знайдено» з посиланням на головну.
- Увесь інтерфейс — українською.

## Пошук

- **Відкрити:** кнопка «Пошук» у меню або `⌘ K` / `Ctrl K`.
- **Українською, за початком слова:** «подільн» знайде «Подільність», «остача» — розділ про ділення з остачею.
- **Шукає по всьому тексту:** заголовки, абзаци, таблиці, підказки. У результатах видно фрагмент з підсвіченим словом і шлях на кшталт «Математика › Теорія».
- **Формули у фрагментах — звичайним текстом:** «−17 = 5 · (−4) + 3», «n² = 25k² + 30k + 9», «−5 ∉ N», а не сирий LaTeX.
- Пошук працює на самому сайті (`/api/search`), без зовнішніх сервісів.

## Теорія

Кожна сторінка теорії має однакову будову:

| Розділ               | Що там                                                                       |
| -------------------- | ---------------------------------------------------------------------------- |
| **Коротко**          | правила, означення, таблиці — все, що треба пам'ятати                        |
| **Простими словами** | звідки це взялося, аналогії, алгоритм, схема (лише якщо тема цього потребує) |
| **Приклади**         | задачі з розв'язком                                                          |
| **Пастки**           | типові помилки в блоці «Не плутай»                                           |

- **Формули** відмальовує KaTeX, як у підручнику: $\frac{12}{4}$, $\sqrt{2}$, $\lvert x \rvert$, системи рівнянь. Числові множини пишуться жирними літерами **N, Z, Q, I, R**, як прийнято на НМТ.
- **Блоки-підказки:** 💡 «Аналогія», «Швидкий спосіб» — щоб легше запам'ятати; ⚠️ «Не плутай» — типові помилки.
- **Тестів у теорії немає:** перевірка знань — лише в практиці.

## Схема числових множин

На сторінці «Числові множини» замість текстового дерева — **інтерактивна діаграма вкладених множин**:

- **Вкладеність наочно:** R (сірий) містить Q (жовтий) та I (рожевий), Q містить Z (зелений), Z містить N (синій). У кожній множині — свої приклади чисел: $1, 2, 3$ / $0, -1, -2$ / $\frac12; -0{,}75; 0{,}(3)$ / $\sqrt2, \sqrt5, \pi$.
- **Наведи мишкою на число** — підсвітяться всі множини, яким воно належить, а решта стане пунктирною. Підсвітка йде за курсором; якщо відвести курсор на порожнє місце, вона зникає (без мерехтіння між сусідніми числами).
- **На телефоні — торкнись числа:** підсвітка лишається після торкання; торкнись іншого числа, щоб перемкнути.
- **З клавіатури** — переходь по числах клавішею `Tab`.
- **Під схемою — підпис:** не лише де число є, а й де його вже немає. Наприклад: «$-1 \in \mathbf{Z}, \mathbf{Q}, \mathbf{R}$; $-1 \notin \mathbf{N}$» або «$\sqrt2 \in \mathbf{I}, \mathbf{R}$; $\sqrt2 \notin \mathbf{Q}$».

## Практика: тренажер

### Що це

Тренажер до теми: 10–15 завдань у форматі НМТ. На сторінці практики немає нічого, крім тренажера: правила — на сторінці теорії, кнопка «← Теорія» під заголовком веде туди.

### Типи завдань

| Тип                   | Як виглядає                                                                                                  | Як відповідати                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| **Вибір відповіді**   | 5 варіантів А–Д, правильний один                                                                             | клік по варіанту або цифра `1`–`5`                               |
| **Відповідність**     | 3 пункти (1–3) і 5 варіантів (А–Д), сітка як у бланку НМТ                                                    | у кожному рядку сітки обрати одну клітинку                       |
| **Коротка відповідь** | поле для числа; у структурованій відповіді — два поля                                                        | ввести число в кожне поле                                        |
| **Кілька правильних** | 3–5 варіантів А–Д, правильних два чи більше (поза форматом НМТ, для тренування правил з кількома прикладами) | клік або цифра перемикає варіант; зараховується лише повний збіг |

**Коротка відповідь приймає різні записи того самого числа:** `−2,5`, `-2.5` і `-5/2` — це одне й те саме; ціле число — просто `4`. Кома й крапка рівноцінні, мінус можна ставити будь-який (`−` чи `-`), пробіли ігноруються. Якщо ввести не число (наприклад, `abc`), тренажер не зарахує помилку, а підкаже: «Введи число, наприклад 4, −2,5 або 0,75».

### Рівні складності

| Позначка      | Що означає                                    | Скільки в тренажері |
| ------------- | --------------------------------------------- | ------------------- |
| ★ легке       | пряме застосування одного правила             | 3–5                 |
| ★★ рівень НМТ | 1–2 кроки, як у реальному тесті               | 5–8                 |
| ★★★ пастка    | завдання на типову помилку з розділу «Пастки» | 2–3                 |

**Порядок:** спочатку легкі, потім рівня НМТ, наприкінці пастки. У межах рівня завдання й варіанти відповідей **перемішуються при кожному проходженні**, тож відповідь не запам'ятовується «за місцем». У відповідності порядок варіантів А–Д фіксований, як у бланку НМТ.

### Перевірка відповіді

Після кнопки «Перевірити» (або `Enter`) з'являється пояснення:

- **«Правильно»** або **«Неправильно. Відповідь: …»** — з правильною відповіддю саме в тому вигляді, як вона виглядає на екрані: «В) √12», «1–А, 2–Б, 3–В», «−2,5»;
- **розв'язок** у 1–2 речення: чому так і чому інші варіанти хибні.

**Кольори після перевірки:**

- вибір відповіді: правильний варіант — зелений, твій хибний — червоний;
- відповідність: зелена клітинка — твоя правильна, червона — твоя хибна, **зелена пунктирна** — правильна, яку ти пропустив;
- коротка відповідь: поле стає зеленим або червоним.

**Смужка прогресу** вгорі картки: кожне завдання — сегмент. Зелений — правильно, червоний — помилка, виділений — поточне.

### Результат

Після останнього завдання — підсумок:

- **рахунок:** «10 / 13»;
- **оцінка:**

  | Результат    | Що скаже тренажер                           |
  | ------------ | ------------------------------------------- |
  | 100%         | «Ідеально! Тему засвоєно.»                  |
  | 80% і більше | «Добре! Повтори помилки — і буде ідеально.» |
  | 50% і більше | «Непогано, але варто перечитати теорію.»    |
  | менше 50%    | «Повернись до теорії і спробуй ще раз.»     |

- **розбивка за правилами теми:** для кожного правила — смужка й «правильно / усього». Зелена, якщо все правильно, червона — якщо є помилки. Одразу видно, що саме треба підтягнути;
- **кнопки:** «Повторити помилки (N)» — лише якщо є помилки, і «Пройти ще раз».

### Повторення помилок

«Повторити помилки» запускає тренажер **лише із завдань, де були помилки**, у новому порядку. Вгорі картки — «Повторення помилок 1 / N». Якщо все виправлено, тренажер запропонує пройти весь тест ще раз. Повторення не впливає на збережений рекорд.

### Збереження результатів

- Над тренажером: «Найкращий результат: 11/13 · останній: 9/13».
- Зберігаються лише **повні** проходження (після кнопки «Результат»), повторення помилок — ні.
- Результати лежать **у цьому браузері** (`localStorage`, ключ `trainer:<тема>`, запис з номером версії — старі результати переживають оновлення сайту): нікуди не надсилаються. В іншому браузері чи на іншому пристрої — свої результати; очищення даних сайту їх стирає. Крім найкращого й останнього результату зберігається історія останніх 20 проходів з датою — її показує сторінка «Прогрес».

## Змішаний тест

Пункт «Змішаний тест» у кінці меню (`/test`): завдання з **усіх** практик упереміш, у складі справжнього НМТ — 15 з вибором відповіді, 3 на відповідність, 4 з короткою відповіддю (поки практик мало — скільки є). Завдання беруться порівну з усіх тем, щоразу випадково; кнопка «Інший набір» складає новий. Проходження, перевірка й повторення помилок — як у практиці; у результатах кожне правило підписане темою («Числові множини: Визначення множини числа»). Рекорд змішаного тесту зберігається окремо від тем.

## Прогрес

Пункт «Прогрес» (`/progress`): зведення з цього браузера за всіма темами з практикою — скільки тем почато, повних проходів, рекорд змішаного тесту, **слабкі правила** (де з двох і більше відповідей правильних менше ніж три чверті) і картка кожної теми: найкращий та останній результат, кількість проходів з датою останнього, правила зі смужками «правильно/усього» — сумарно з практики й зі змішаного тесту. Тема без проходів позначена «Ще не проходив».

## Як додати контент

### Нова тема

Кожна тема — папка в розділі програми: `content/<розділ>/<slug>/`. Усе, що стосується теми, лежить у ній.

Найпростіше — командою **`/theory <розділ>/<slug>`** у Claude Code з матеріалом (файл або текст): skill пише теорію за форматом, перераховує приклади, викликає `math-checker` і проганяє перевірки. Руками:

1. Створи `content/numbers/<slug>/index.mdx` (розділ `numbers` — «Числа»; новий розділ — нова папка з `meta.json`). `<slug>` — англійською в kebab-case, без номерів, наприклад `fractions`.

   ```mdx
   ---
   title: Звичайні дроби
   description: Скорочення, зведення до спільного знаменника, дії з дробами.
   ---

   ## Коротко

   ...
   ```

2. Додай slug у `content/numbers/meta.json` — у те місце списку `pages`, де тема має стояти в порядку вивчення. Якщо забути, тема все одно з'явиться в меню, але в кінці.
3. Пиши за форматом: Коротко → Простими словами → Приклади → Пастки. Детальні правила запису формул і MDX — у `.claude/rules/content.md`.
4. `npm run check` — за секунди покаже зламані формули, зайві розділи, слова не зі словника.

Велику тему краще ділити на підсторінки в тій самій папці: `content/numbers/<slug>/<сторінка>.mdx`.

### Практика до теми

Практику створює Claude командою **`/practice <slug>`** (наприклад, `/practice modulus`). Skill складає 10–15 завдань за правилами складу, перераховує кожну відповідь, віддає файл агентові `math-checker`, проганяє `npm run check` і `npm run verify`. Нічого вручну прописувати не треба: тренажер, пункт «Практика» в меню, кнопки переходу й тести з'являються самі. «`/practice modulus` — додай 3 завдання на …» дописує завдання до наявної практики.

Файл практики — `content/<розділ>/<slug>/practice.mdx` поруч з `index.mdx` теми: лише frontmatter із блоком `trainer:`, тексту під ним немає (правила — в теорії).

### Головне про запис формул

| Що                                | Як писати                                                                     |
| --------------------------------- | ----------------------------------------------------------------------------- |
| формула в тексті / окремим рядком | `$...$` / `$$...$$`                                                           |
| множини                           | `\N \Z \Q \I \R`                                                              |
| десяткова кома у формулі          | `0{,}25`                                                                      |
| модуль у таблиці                  | `\lvert x \rvert` (символ `\|` ламає таблицю)                                 |
| підказка / пастка                 | `<Callout type="idea" title="…">` / `<Callout type="warn" title="Не плутай">` |

## Перевірки якості

**`npm run check`** — швидка перевірка після кожної правки (секунди): контент → типи → лінтер → юніт-тести. **`npm run verify`** — повна перед комітом: `check` → мертвий код → форматування → збирання → браузерні тести.

### Перевірка контенту (`npm run check`, hook після збереження) ловить за секунди

- усі зламані формули файлу одразу, з рядком;
- розділи теорії не з формату або не в порядку Коротко → Простими словами → Приклади → Пастки;
- слова «урок», «питання»; мінус `-` і десяткова крапка поза формулами; `|` у формулі в таблиці;
- практику без теорії поруч, повторний slug теми (ключ прогресу), `meta.json` з неіснуючими сторінками чи іконкою.

### Збирання зупиняється з поясненням українською, якщо

- **тренажер оформлено не за правилами:** не 5 варіантів, не той склад рівнів чи типів, тег не описаний або не використаний, однакові умови, варіант «усі перелічені», однакові відповіді у відповідності, у «кілька правильних» менше двох або всі правильні;
- **у формулі помилка** — з точним місцем: `content/numbers/modulus/index.mdx:30:3: Помилка у формулі: KaTeX parse error…`;
- **варіант відповіді чи назва правила не в один рядок** (умова й пояснення можуть мати кілька абзаців, виносні формули й таблиці); незнайоме поле в завданні; рисунок завдання не знайдено;
- **тренажер не на своєму місці:** `practice.mdx` без блоку `trainer` або блок `trainer` у файлі теорії.

## Робота з Claude Code

- **[AGENTS.md](AGENTS.md)** — карта проєкту для AI-агента: стек, структура, команди, як додати, Definition of Done. `CLAUDE.md` — посилання на нього, Claude Code читає його на початку кожної сесії. Детальні правила — у `.claude/rules/`.
- **Skills:** `/theory <розділ>/<slug>` — теорія теми з матеріалу власника, `/practice <slug>` — тренажер до теми, `/review-topic <slug>` — ревʼю теми без змін (`.claude/skills/`).
- **Агент `math-checker`** (`.claude/agents/`) — незалежно перераховує кожну відповідь і приклад у файлі; skills викликають його перед завершенням.
- **`npm run check`** — перевірка контенту без збирання за 1–3 с (`scripts/check-content.ts`): формули (усі помилки одразу), структура теорії, словник, `meta.json`. Hook у `.claude/settings.json` запускає її для кожного збереженого файлу контенту.
- **Правила за шляхами** — `.claude/rules/*.md` підвантажуються, коли Claude править контент, тренажер або тести; `AGENTS.md` лишається короткою картою.
- **CI** — `.github/workflows/verify.yml` ганяє `npm run verify` на push і PR.
- **MCP-сервери** (`.mcp.json`): `next-devtools` (документація й діагностика запущеного Next.js) і `shadcn` (каталог компонентів). Під час першого запуску Claude Code попросить дозвіл.
- **`.claude/launch.json`** — запуск dev-сервера для перегляду сайту прямо в Claude.

## Нюанси та обмеження

- **Результати тренажера — лише в цьому браузері.** Синхронізації між пристроями немає; сторінка «Прогрес» читає ті самі записи. Очистити дані сайту в браузері — означає втратити прогрес.
- **Завдання лише статичні.** Увесь текст завдань (формули, варіанти) перетворюється на HTML під час збирання, тому KaTeX у браузер не потрапляє. Завдань із випадковими числами, що генеруються при кожному відкритті, немає і в цій моделі не буде — це окреме рішення.
- **Рисунок до завдання — лише картинка** (svg, png, jpg, webp з папки теми), вбудована в сторінку під час збирання. Інтерактивні схеми можливі лише в теорії.
- **Перший запуск і збирання потребують інтернету:** Next.js завантажує шрифт Inter, далі він береться з кешу.
- **`npm audit`** показує `braces` (high): це лише інструменти розробки (ESLint, shadcn CLI), виправленої версії поки немає, на сайт не впливає.
- **TypeScript 7 не ставити:** з ним падає лінтер (`typescript-eslint` поки підтримує до 6.0).
- **Оновлення залежностей:** пакети Fumadocs (`fumadocs-core`, `fumadocs-ui`, `fumadocs-mdx`) оновлювати разом; `next` і `eslint-config-next` — однієї версії. KaTeX примусово 0.19 через `overrides` у `package.json` — прибрати, коли `rehype-katex` перейде на нову версію сам.
