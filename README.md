# Математика · НМТ

Особистий сайт для підготовки до НМТ з математики: теорія і практика за темами.

## Запуск

Потрібен Node.js 22.12+ (рекомендовано 24 LTS, див. `.nvmrc`).

```bash
npm install
npm run dev
```

Сайт відкриється на http://localhost:4321. Навігація — меню зліва, пошук — угорі.

## Як влаштовано

| Розділ      | Що там                                            | Де лежить                              |
| ----------- | ------------------------------------------------- | -------------------------------------- |
| 📖 Теорія   | тема: коротко, простими словами, приклади, пастки | `src/content/docs/theory/<тема>.md`    |
| 🏋️ Практика | завдання у форматі НМТ з перевіркою й поясненнями | `src/content/docs/practice/<тема>.mdx` |

Теорію й практику однієї теми пов'язує однакова назва файлу.

## Команди

| Команда                     | Що робить                                                    |
| --------------------------- | ------------------------------------------------------------ |
| `npm run dev`               | сайт з автооновленням                                        |
| `npm run verify`            | повна перевірка: типи, лінтер, форматування, тести, збирання |
| `npm run build` / `preview` | зібрати статичний сайт у `dist/` / переглянути його          |
| `npm run dev:clean`         | як `dev`, але зі скиданням кешу (див. нижче)                 |

Якщо практика зависла на «Завантаження тренажера…» — зупини сервер, запусти `npm run dev:clean` і перезавантаж сторінку з `Cmd+Shift+R`.

Правила для AI-агента — у [AGENTS.md](AGENTS.md) (`CLAUDE.md` — посилання на нього).
