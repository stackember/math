# AGENTS.md

Особистий сайт для підготовки до НМТ з математики: теорія і практика за темами. Користувач вчиться з рівня шкільної програми й сам дає матеріал по темах; сайт не прив'язаний до конкретних підручників.

## Стек

- **Next.js 16** (App Router, Turbopack) + **Fumadocs 16**: меню, пошук, зміст сторінки, світла/темна тема. UI Fumadocs — пакет `@fumadocs/base-ui` (встановлений під іменем `fumadocs-ui`).
- **fumadocs-mdx 15**: колекції через macro-виклик у `src/lib/source.ts`, глобальні MDX-плагіни — у `source.config.ts`.
- **KaTeX 0.19** (`remark-math` + `rehype-katex`). У `package.json` → `overrides` KaTeX примусово 0.19 для всього дерева: `rehype-katex` тягне 0.16 з відомою вразливістю.
- **React 19 + shadcn/ui** (стиль `base-nova`, примітиви Base UI) + **Tailwind 4**. Fumadocs бере кольори з тих самих токенів shadcn (`fumadocs-ui/css/shadcn.css`) — одна палітра.
- **Zod 4**, **TypeScript 6**, **Vitest**, **Playwright**, ESLint (`eslint-config-next`), Prettier.
- TypeScript 7 **не ставити**, доки `typescript-eslint` його не підтримує (зараз — до 6.0): лінтер падає.

Перш ніж писати код під Next.js / Fumadocs / shadcn — звір з актуальною документацією. Пам'ять моделі може бути застарілою:

- Next.js: документація саме встановленої версії — `node_modules/next/dist/docs/`; MCP `next-devtools` (`.mcp.json`) дає помилки й маршрути запущеного `npm run dev`.
- Fumadocs: https://fumadocs.dev/docs і типи в `node_modules/fumadocs-*/dist`.
- shadcn: MCP `shadcn`.

## Команди

- `npm run dev` — сайт на http://localhost:3000.
- `npm run verify` — typecheck + lint + format:check + test + build + test:e2e. **Запускати перед завершенням роботи.**
- Окремо: `typecheck`, `lint`, `format`, `test` (Vitest), `build`, `test:e2e` (Playwright, потребує свіжого `build`; сервер на порту 3100).

## Структура

```
content/                        контент (MDX)
  index.mdx                     головна «Як вчитися»
  meta.json                     порядок розділів
  theory/meta.json              назва розділу й порядок тем
  theory/<slug>.mdx             📖 теорія теми
  practice/meta.json            назва розділу (порядок — автоматично, як у теорії)
  practice/<slug>.mdx           🏋️ практика до теми з тим самим <slug> — лише коли потрібна
source.config.ts                MDX-плагіни: KaTeX, читабельні формули в пошуку
src/lib/source.ts               колекція content/ + схема frontmatter (quiz — для практики)
src/lib/topics.ts               пара theory/<slug> ↔ practice/<slug>; порядок практики в меню
src/lib/quiz/                   схема й правила тренажера (schema.ts), перевірка, сесія, рендер формул
src/lib/latex-text.ts           LaTeX → текст для індексу пошуку
src/lib/i18n.ts                 українські підписи інтерфейсу Fumadocs
src/app/layout.tsx              шрифт, провайдер, DocsLayout з меню
src/app/[[...slug]]/page.tsx    сторінка контенту: заголовок, кнопка теорія↔практика, <Trainer />
src/components/trainer/         тренажер: Trainer (сервер) → QuizLoader (лише браузер) → Quiz
src/components/diagrams/        інтерактивні схеми для теорії (напр. <NumberSets />)
src/components/ui/              shadcn — лише через `npx shadcn@latest add <name>`, руками не правити
e2e/                            Playwright-тести
```

Юніт-тести — поруч із кодом (`*.test.ts`).

## Як додати

- **Тему:** `content/theory/<slug>.mdx` з `title` і `description` + slug у `pages` файлу `content/theory/meta.json` у потрібне місце (порядок вивчення). Велику тему ділити на кілька сторінок.
- **Практику:** тільки skill `/practice <slug>`. У меню вона стане в порядку теорії сама; практика без теорії — помилка збирання.
- **Компонент shadcn:** `npx shadcn@latest add <name>`.

Назви файлів — англійською в kebab-case, без номерів (`modulus.mdx`): адреси сторінок і збережені результати не ламаються, коли змінюється порядок.

## Формат теорії

Зразок — `content/theory/number-sets.mdx`. Розділи:

1. `## Коротко` — правила, означення, таблиці.
2. `## Простими словами` — лише якщо тема цього потребує: звідки взялося, аналогія (`<Callout type="idea" title="Аналогія">`), алгоритм.
3. `## Приклади` — з розв'язком.
4. `## Пастки` — типові помилки в `<Callout type="warn" title="Не плутай">`.

**Без тестів і вправ** у теорії: перевірка знань — лише в практиці.

## Формули й MDX

- Inline `$...$`, блок `$$...$$` з порожніми рядками навколо.
- Множини — макроси `\N \Z \Q \I \R` (жирні; `src/lib/math.ts`).
- Десяткова кома у формулі — `0{,}25`; поза формулами — `0,25`. Списки чисел з дробами — через `;`.
- Мінус у формулі — звичайний `-`; у тексті поза формулами — `−`.
- У таблицях модуль — `\lvert x \rvert`: символ `|` ламає таблицю.
- У MDX `{`, `}` і `<` поза формулами й кодом — це JSX: не використовувати.
- Компоненти без імпорту: `Callout` (`type`: `idea`, `warn`, `info`, `success`, `error`), `Steps`/`Step`, `Cards`/`Card`, схеми (`<NumberSets />`); на сторінках практики — `<Trainer />`. Новий компонент для MDX — реєструвати в `src/components/mdx.tsx`.

## Схеми й ілюстрації

- Схема, що показує ідею теми (вкладеність, відстань, поділ), — свій компонент у `src/components/diagrams/`: серверна частина рендерить формули KaTeX, клієнтська (`"use client"`) — лише інтерактив. Кольори — Tailwind з `dark:`-варіантами, стан — у `data-*` атрибутах (на них спираються e2e-тести).
- Графіки функцій, координатна площина, геометрія — бібліотека Mafs (ставити, коли з'явиться перша така тема).
- Блок-схеми алгоритмів — Mermaid (так само — лише за потреби).
- Усередині `<Callout>` / `<Step>` — порожній рядок після відкриваючого й перед закриваючим тегом, інакше Markdown (списки) не розбереться.
- Prettier контент не форматує (`content/` у `.prettierignore`): він міняє лапки в YAML і ламає LaTeX.

## Архітектурні рішення

- **Тренажер рендериться лише в браузері** (`next/dynamic` з `ssr: false` у `QuizLoader`): порядок завдань випадковий, результати — з `localStorage`; серверний HTML розійшовся б із браузерним (помилка гідрації). Формули завдань рендеряться на сервері під час збирання (`Trainer` → `renderQuiz`).
- **Перевірки під час збирання:** схема тренажера (склад, теги, варіанти — `src/lib/quiz/schema.ts`), практика без теорії (`src/lib/topics.ts`). Повідомлення — українською.
- **Пошук** — вбудований Orama Fumadocs (`/api/search`), багатомовний. Формули в індексі — текстом через `latexToText`.
- Ключ збережених результатів — `trainer:practice/<slug>`: не змінювати, інакше пропаде прогрес.

## Правила

- Кожну числову відповідь і приклад перевіряй обчисленням (`python3` / `node`), перш ніж записати.
- Зміни у вигляді перевіряй у браузері (`npm run dev`) і e2e-тестами, а не лише збиранням.
- Нові залежності — лише за потреби, актуальні стабільні версії, сумісність перевіряй, а не обходь (`--force`, `--legacy-peer-deps` — ні).
- `npm audit`: лишається `braces` (high) — лише в інструментах розробки (ESLint, shadcn CLI), виправленої версії поки немає; на сайт не впливає.
- Не створюй файли «про запас»: порожні теми, практику без запиту.
