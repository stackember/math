# AGENTS.md

Особистий сайт для підготовки до НМТ з математики. Користувач вчиться з рівня шкільної програми й сам дає матеріал по темах; сайт не прив'язаний до конкретних підручників.

## Стек

- **Astro 7 + Starlight** — сайт, меню, пошук, світла/темна тема.
- **KaTeX** — формули: `remark-math` + `rehype-katex` через процесор `unified` з `@astrojs/markdown-remark` (типовий для Astro 7 Sätteri має KaTeX лише через сторонній плагін).
- **React 19 + shadcn/ui** (стиль `base-nova`, примітиви Base UI) + **Tailwind v4** — лише для практики (тренажерів).
- **Zod-схеми** в content collections, **Vitest**, ESLint, Prettier.

Перш ніж писати код для Astro/Starlight/shadcn — звір з актуальною документацією через MCP `astro-docs` і `shadcn` (`.mcp.json`). Пам'ять моделі може бути застарілою: Astro 7 вийшов у червні 2026.

## Команди

- `npm run dev` — сайт на http://localhost:4321. Агенту: `npx astro dev --background`, далі `npx astro dev stop | status | logs`.
- `npm run verify` — check + lint + format:check + test + build. **Запускати перед завершенням роботи.**
- Окремо: `npm run check` (типи + схеми контенту), `lint`, `test`, `build`, `format`.
- `npm run dev:clean` — dev зі скиданням кешу залежностей Vite. Потрібен, якщо в dev практика зависла на «Завантаження тренажера…» з помилкою `_jsxDEV is not a function` / `dispatcher.getOwner is not a function` (дві копії React після перезапуску сервера — баг Vite 8, vitejs/vite#20609; на `build` не впливає). Після запуску — жорстке перезавантаження сторінки.

## Структура

```
src/content/docs/
  index.mdx               як вчитися
  theory/<slug>.md        📖 теорія теми
  practice/<slug>.mdx     🏋️ практика до теми з тим самим <slug> — лише коли потрібна
src/lib/topics.ts         угоди про сторінки: пара theory/<slug> ↔ practice/<slug>
src/lib/quiz/             схема й правила тренажера (schema.ts), перевірка, сесія, рендер формул; тести *.test.ts поруч
src/components/trainer/   UI практики (React)
src/components/ui/        shadcn — лише через `npx shadcn@latest add <name>`, руками не правити
src/components/overrides/ перевизначення Starlight: PageTitle (кнопка «Практика» / «← Теорія»),
                          TwoColumnContent (зміст справа фіксованої ширини, контент по центру)
```

- **Меню** будується з папок `theory/` і `practice/` автоматично. Порядок — `sidebar.order` у frontmatter з кроком 10 (10, 20, 30…), щоб нову тему можна було вставити між наявними без перейменувань.
- **У практики той самий `order`, що в її теорії** — інакше збирання впаде з поясненням.
- **Назви файлів** — англійською в kebab-case, без номерів (`modulus.md`): адреси сторінок і збережені результати не ламаються, коли змінюється порядок.

## Як додати

- **Тему:** `theory/<slug>.md` з `title`, `description`, `sidebar.order`. Велику тему — ділити на кілька сторінок.
- **Практику:** тільки skill `/practice <slug>`.
- **Компонент shadcn:** `npx shadcn@latest add <name>`.

## Формат теорії

Зразок — `theory/number-sets.md`. Розділи:

1. `## Коротко` — правила, означення, таблиці.
2. `## Простими словами` — лише якщо тема цього потребує: звідки взялося, аналогія (`:::tip`), алгоритм.
3. `## Приклади` — з розв'язком.
4. `## Пастки` — типові помилки в `:::caution[Не плутай]`.

**Без тестів і вправ** у теорії: перевірка знань — лише в практиці.

## Формули й Markdown

- Inline `$...$`, блок `$$...$$` з порожніми рядками навколо.
- Множини — макроси `\N \Z \Q \I \R` (жирні; `src/lib/math.ts`).
- Десяткова кома у формулі — `0{,}25`; поза формулами — `0,25`. Списки чисел з дробами — через `;`.
- Мінус у формулі — звичайний `-`; у тексті поза формулами — `−`.
- У таблицях модуль — `\lvert x \rvert`: символ `|` ламає таблицю.
- `.md` — для теорії; `.mdx` — лише коли потрібні компоненти (у MDX `{` і `<` поза формулами — це JSX).

## Правила

- Кожну числову відповідь і приклад перевіряй обчисленням (`python3` / `node`), перш ніж записати.
- Зміни у вигляді перевіряй у браузері, а не лише збиранням.
- Нові залежності — лише за потреби, актуальні стабільні версії, сумісність перевіряй, а не обходь (`--force`, `--legacy-peer-deps` — ні).
- Не створюй файли «про запас»: порожні теми, практику без запиту.
