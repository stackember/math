# Новий предмет

Аргументи: `$ARGUMENTS` — slug латиницею (це адреса `/<slug>` і папка), назва українською, id профілю іспиту. Якщо чогось немає — спитай.

Предмет — це **коренева папка контенту**: Fumadocs робить з неї вкладку в меню, тренажер бере профіль іспиту з її `meta.json`, Claude читає правила предмета з `.claude/rules/subjects/`. Контент (теми, практики) додається потім skills `/theory` і `/practice`.

## Кроки

1. **Профіль іспиту.** Якщо `<профіль>` є в `src/features/trainer/model/exam/registry.ts` — нічого не робиш. Якщо ні — файл `exam/<профіль>.ts` за зразком `nmt-math.ts` (літери, відповідність, поля короткої відповіді, межі `multi`, склад практики, склад змішаного тесту, рівні) з даних офіційної характеристики іспиту + запис у `EXAM_PROFILES`. Юніт-тест прикладів типів ганяється за профілем за замовчуванням, тож новий профіль перевіряється складом практик.
2. **`content/<slug>/meta.json`:**
   ```json
   { "title": "<Назва>", "description": "Одне речення — що перевіряє іспит", "icon": "<іконка lucide>", "root": true, "exam": "<профіль>", "pages": ["index", "..."] }
   ```
3. **`content/<slug>/index.mdx`** — огляд предмета: `title`, `description`, як вчитися (зразок — `content/math/index.mdx`). Це сторінка `/<slug>`.
4. **`content/meta.json`** — slug у `pages` на потрібне місце (порядок предметів на головній і у вкладках).
5. **`.claude/rules/subjects/<slug>.md`** з `paths: ["content/<slug>/**"]` за зразком `math.md`: основа (програма іспиту), що входить, джерела, позначення (для хімії — `\ce{}` з mhchem, для фізики — одиниці), формат теорії, вимоги до практики, типові пастки.
6. **`npm run check`** — перевіряє `meta.json` предмета (root, exam з реєстру), наявність index.mdx, типи. Потім `npm run rules -- <slug>` має надрукувати склад профілю.
7. Якщо предмету потрібні власні схеми — підпапка `<slug>/` у сегментах `src/features/diagram/`; свої плагіни формул — у `src/shared/lib/math.ts` (глобальні, не заважають іншим предметам).

Змішаний тест `/<slug>/test` і прогрес `/<slug>/progress` зʼявляються самі (`src/app/[[...slug]]/subject-pages.tsx`). Змішаний тест бере завдання з усіх предметів того самого профілю — так виглядає реальний іспит.

Старі адреси при перейменуванні предмета — редирект у `next.config.mjs`; slug предмета після публікації не змінювати (ключ прогресу `trainer:<slug>/<тема>`).
