# Ревʼю теми

Тема: `$ARGUMENTS` — `<предмет>/<slug>` (папка `content/<предмет>/<розділ>/<slug>/`); розділ знайди пошуком. Правила предмета — `.claude/rules/subjects/<предмет>.md`. Файли не змінюй: результат — звіт.

## Що перевірити

1. **Автоматика:** `npx tsx scripts/check-content.ts content/<предмет>/<розділ>/<slug>/index.mdx content/<предмет>/<розділ>/<slug>/practice.mdx` — усе, що знайде, у звіт як є.
2. **Математика:** запусти агента `math-checker` на кожен файл теми; його список — у звіт.
3. **Формат теорії** (`.claude/rules/content.md`): чотири розділи, правило → приклад з розв'язком, «Пастки» з типових помилок, без тестів у теорії, терміни проєкту.
4. **Практика** (`.claude/rules/trainer.md`): кожен тег покрито; хибні варіанти — типові помилки, а не випадкові числа; немає двох завдань одного шаблону з іншими числами; складність відповідає рівню (★ пряме правило, ★★ 1–2 кроки як на НМТ, ★★★ пастка з теорії); `why` пояснює, чому інші варіанти хибні; завдання відповідають тому, що пояснено в теорії.
5. **Доступність і вигляд:** `alt` у рисунків, формули не в заголовках без потреби, таблиці не ширші за екран телефону (довгі рядки, `|` у формулах).

## Формат звіту

Список `файл:рядок — проблема — як виправити`, згрупований: математика → формат → завдання → доступність. Наприкінці — одне речення: чи можна публікувати тему як є.
